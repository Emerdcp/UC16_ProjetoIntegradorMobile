Sobre o sistema

Um projeto pensado para operação

Uma solução mobile para consultar informações e acompanhar as principais atividades do ControlPro de forma rápida.

O que é o ControlPro?

O ControlPro centraliza informações importantes para o acompanhamento de clientes, atendimentos e compromissos. O aplicativo foi pensado para facilitar o acesso às informações durante a rotina de trabalho.

React NativeAplicativo mobile
TypeScriptDesenvolvimento tipado
Node.jsAPI e regras de negócio
MariaDBBanco de dados

Principais módulos

02AtendimentosConsulta e acompanhamento do ciclo de atendimento.
03ClientesConsulta e gerenciamento das informações dos clientes.
04AgendaVisualização de compromissos e calendário.
